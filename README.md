# arooshi-python-calculator

Scientific Calculator Using Python

About the Project

This is a menu-driven scientific calculator developed using Python as a beginner-level programming project.

Features

Addition
Subtraction
Multiplication
Division
Modulus
Exponentiation
Square Root
Continuous calculations using a loop
Technologies Used

Python
Math Module
Concepts Learned

Functions
While Loops
Conditional Statements
User Input
Lists
Basic Error Prevention
How to Run

Install Python on your computer.
Download the calculator.py file.
Open a terminal in the project folder.
Run:

bash
python calculator.py
